# 三国棋·争霸 (Three Kingdoms Chess)

一款单文件 HTML 策略棋牌小游戏，纯前端实现，无需任何依赖，浏览器双击即玩。

## 启动方式

直接双击 `index.html` 即可在浏览器中打开游戏（推荐 Chrome / Edge / Firefox）。

或者使用本地静态服务器：
```
python -m http.server 8000
# 然后浏览器访问 http://localhost:8000
```

## 玩法

- **棋盘**：8×6 网格，两端为双方大本营
- **胜利条件**：任一方单位踏入对方大本营
- **每回合**：抽 5 张牌，恢复 10 体力
- **体力消耗**：召唤武将 = 武将费用；移动每步 = 1 体力
- **每武将每回合**：可移动 1-2 步（移动力），可攻击 1 次（无双可 2 次）

### 操作
- 点击 **手牌** → 点击己方半场空格（黄格） → 召唤武将
- 点击 **场上我方武将** → 点击绿格 移动 / 点击红格 攻击
- 点击 **结束回合** → 切换到 AI

### 势力
- **蜀汉**（推荐新手）：赵云、关羽、张飞、诸葛亮、刘备、黄忠
- **曹魏**：夏侯惇、夏侯渊、司马懿、曹操、张辽
- **东吴**：周泰、甘宁、太史慈、周瑜、孙策

### 难度
- **简单**：AI 随机出牌 + 贪心攻击
- **普通**：AI 评估性价比（推荐）
- **困难**：AI 启发式评估，攻防兼顾

## 文件

- `index.html` — 游戏全部代码（HTML + CSS + JS）

无第三方依赖，无构建步骤，单文件即可运行。
